# Menu That Feeds a Mangrove

**Menu That Feeds a Mangrove** is a cozy coastal café and mangrove conservation game set in Bang Khun Thian.

Players run an eco-café, prepare dishes with local ingredients, serve customers, and complete conservation missions that help restore the mangrove ecosystem. Make thoughtful menu choices, protect the coastline, and build relationships with the coastal community.

## About the Game

- Run a café by the mangroves
- Discover local ingredients and recipes
- Complete environmental conservation missions
- Care for the surrounding ecosystem
- Build friendships across the coastal community
